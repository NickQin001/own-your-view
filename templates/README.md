# templates/ — 共识观点库模板（公开仓）

本目录给 **own-your-view** 的「共识观点库 MVP」提供空模板与虚构示例。

## 公开仓放什么 / 不放什么

| 放 | 不放 |
|----|------|
| `views/consensus.empty.json`（空数组 `[]`） | 你的真实共识条目 |
| `views/consensus.example.json`（虚构示例，标明示例） | 含隐私或可识别信息的推敲记录 |
| 本 README | 个人绝对路径、bot 名、自动同步/邮箱通知配置 |

真实「共识观点 / 现行判断」只应存在于 **你本机或个人工作区**（或你环境约定的枢纽位置），**不进**公开 GitHub 默认树。

## 形态（S2′）

- **单一 JSON 数组文件**：位置由用户主目录的 `.own-your-view/config.json` 固定，同一用户跨工作区复用。
- 数组内**只含**已确认入库的条目；每条含 F1 字段，并含 `updated_at`（ISO 8601）。
- 不是一条一个 markdown；不把聊天记录整段塞进库。

## 配置路径和首次使用

配置是本 Skill 定义的普通 JSON 文件，不是宿主原生配置。以下路径值仅作占位说明；实际写入必须是当前环境核验过的绝对路径，不含 `~` 或未展开的环境变量：

```json
{"schema_version": 1, "library_path": "<ABSOLUTE_LIBRARY_PATH>"}
```

1. 模板只用于查看结构；阅读模板、安装 Skill 或查看观点库时不提前创建观点库文件或写入观点。首次调用仍可按下一步建立路径配置。需要对照字段时，打开 `consensus.example.json`（虚构，勿当真实条目）。
2. 首次调用在实际用户主目录下保存并读回 `.own-your-view/config.json`：已有明确库位置或当前工作区的旧版 `views/consensus.json` 时沿用其绝对路径；没有旧库时选择主目录下的 `.own-your-view/consensus.json`。只初始化路径配置，不创建观点库。
3. 你明确确认入库后才创建或更新实际库，并读回核验。不同工作区和子目录读取同一配置；不自动扫描、搬迁或合并其他库。跨设备同步不是该配置的能力，已有明确共享枢纽映射仍有效。
4. 正常查看直接展示条目；文件不存在时说明尚无库，读取失败或数据损坏时报告具体问题，不报告为空库、不覆盖损坏文件。
5. 配置损坏、版本不支持、路径非绝对或位置无法访问时报告实际问题，不静默建立工作区备用库。临时读取用户指定另一份库不改变默认配置。

## 与 Skill 职责的关系（摘要）

- **写入职责**：推敲并在确认后落盘。
- **决策复查职责**：计划/决策且主题相关时读库，以「智者建议 / 既往共识」提出，**不代拍板**。
- 默认当前助手兼两职；可选覆盖映射见 Skill 正文。

细节以仓库内 `skills/own-your-view/SKILL.md` 为准。
