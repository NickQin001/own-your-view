# Own Your View · 想清楚，再相信

[English](README.md) · 作者：[NickQin001](https://github.com/NickQin001) · [MIT 许可证](LICENSE)

仓库地址：[https://github.com/NickQin001/own-your-view](https://github.com/NickQin001/own-your-view)

早期试用版 v0.1.1 · 2026-10-14 · [GitHub 项目](https://github.com/NickQin001/own-your-view)

听到一句很有道理的话之后，我们可能愿意相信它，甚至照着做。这个 Skill 希望在两者之间留一点空间：检查依据、看看反例，再决定哪些部分值得保留。

它不以说服你认同 AI 为目标，也不承诺把观点打磨成“绝对正确”。你可以反驳 AI、保留原观点、暂不确定，或随时结束。

## 为什么准备放到 GitHub

希望找到也有“共鸣之后想再检查一次”需求的人，通过实际使用的问题和建议一起改进。发布意图是邀请试用与讨论，不是宣称方法成熟或学习效果已经被证明。

本项目采用 MIT 许可证，允许使用、修改、再分发和商业使用，要求保留版权与许可声明。项目由 NickQin001 发起，使用 AI 辅助起草与检查。一个 Windows Codex 环境的安装与技能发现已检查；尚无跨平台兼容或真实用户效果验证。

## 快速开始

### Codex 用户：安装一次，以后按名称调用

先查看 [v0.1.1 核心指令](https://github.com/NickQin001/own-your-view/blob/v0.1.1/skills/own-your-view/SKILL.md)。在你自己的 Codex 对话框复制下面这段：

```text
$skill-installer

请安装我选择的 Skill：
仓库：https://github.com/NickQin001/own-your-view
技能目录：skills/own-your-view
版本：v0.1.1

只将这个技能安装到我的 Codex 个人技能目录。
若已有同名安装，先检查，未经我同意不要覆盖。
不要修改其他技能、全局指令或无关设置。
完成后核对技能名为 own-your-view，并告诉我如何调用。
```

这是发给 Codex 的提示，不是终端命令。由你在自己的设备上主动发起安装，环境要求的权限由你审批；收到仓库链接不会自动安装。如果你的环境没有 `$skill-installer`，可先用下方免安装方式。

安装完成后，在下一条消息中使用：

```text
$own-your-view

我读到一个观点：“工具越多，工作就越高效。”
它让我产生共鸣的理由是：工具能减少重复劳动。
请帮我推敲，暂时不要替我改写观点。
```

在 Codex 输入 `$` 后选择 `own-your-view`，也可通过 `/skills` 查找。若没有出现，重启 Codex 后再检查。安装和调用方式见 [OpenAI 官方说明](https://learn.chatgpt.com/docs/build-skills)。本项目目前只检查了一个 Windows Codex 环境；没有认证其他环境或自动选择技能的行为。

### 普通 AI 对话：先免安装试用

从 [v0.1.1 下载页](https://github.com/NickQin001/own-your-view/releases/tag/v0.1.1)下载 ZIP 并解压。完整提示词在 [skills/own-your-view/SKILL.md](skills/own-your-view/SKILL.md)，不是 README。把这个文件上传给能读取文本文件的 AI，或粘贴其完整内容，再发送：

```text
请完整读取我提供的 SKILL.md，并按照其中的规则帮我推敲观点。
如果无法读取完整文件，请先说明，不要假装已经读取。

我的观点：工具越多，工作就越高效。
我产生共鸣的理由：工具能减少重复劳动。
我想检查的问题：这个结论在哪些情况下不成立？

请先从一个关键问题或反例开始，暂时不要替我改写观点。
```

把观点、理由和问题换成自己的内容即可。这是按文件指令开展对话，不等于原生 Skill 安装，也不意味着普通聊天中能使用 `$own-your-view`。能读取本地文件的 AI，也可直接读取解压后仓库中的 `skills/own-your-view/SKILL.md`，相对路径以仓库文件夹为基准。

回复默认跟随你的提问语言，也可以明确要求另一种语言。英文安装与调用示例并不代表存在第二套英文核心规则；核心仍只维护一份中文指令。中文提问中引用英文，不会仅因引文而切换回复语言。语言适配依赖所用模型，覆盖与限制见检查记录。

也可以只提供自己的概括，不必上传原文或全部资料。若判断需要原话或具体事实，AI 应说明需要哪一小段、为什么。发给朋友时只需分享技能文件和仓库链接，不必分享自己的私人对话。

### 已安装副本怎样更新

上述提示固定安装 `v0.1.1`。GitHub README 或本地源稿变化，不会自动更新已经安装的副本。查看新版本后，再主动要求安装器更新，并先保留自己的本地修改。本次快速开始更新位于 `main`，已有 v0.1.1 标签和 ZIP 保留原始快照，核心指令相同。

## 可以期待什么

AI 可以直接指出问题或举反例，通常一次聚焦一个关键问题。推荐改写默认等你回应后再给；你也可以直接说“先帮我改一版”。事实和来源需要查证，偏好可以保留；没有检索能力时应明确哪些还不知道。

适合验证的正常收尾会留下一项可选的小验证，或者一个需要查证的问题；仅请求整理、解释或表达偏好时，不额外添加作业。你不必完成作业才能结束。实践可能让你继续做、调整做法，也可能让你决定不做；这些都不是失败。

## 试用边界

首版面向主动检查日常观点和阅读感悟的使用情境，不是课堂考核、心理诊断或高风险专业决策工具。检索依赖宿主环境实际提供的能力；Skill 本身不增加联网权限。

有两种不同的检验：规则模拟检查只能观察 AI 的行为；自愿参与的换情境测试，才开始观察用户能否独立判断。两者都不足以单独证明长期认知提升。

本包无遥测、自动反馈提交或持久用户画像；这不等于宿主 AI 平台不保存聊天，私人内容仍需按所用平台的设置和政策处理。公开反馈前请自己检查脱敏范围。
