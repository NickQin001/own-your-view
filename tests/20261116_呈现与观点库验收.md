# 结构化呈现与固定观点库验收

本轮使用虚构场景，检查规则行为，不验证长期认知效果。对话案例覆盖：初次推敲、用户新增限定、仅说有道理、指出不适用反例、直接解释、要求总结但不保存、明确停止、明确指定六段、未调用本 Skill 的普通方案审查。

存储案例覆盖：明确工作区根且 cwd 位于子目录、两个工作区、明确覆盖路径、文件不存在、损坏 JSON、认可但暂不保存、确认追加并保留旧条目、首次确认后创建。

每项保存输入、实际响应及必要的工具证据，不把预期结果写成执行结果。多场景若在同一新代理线程批量执行，必须注明共享上下文与提前可见的后续输入，不能称为逐项独立盲测。无第二模型实测时跨模型验证记为未覆盖。

所有写入仅使用隔离的虚构观点库，检查默认/覆盖路径、已有条目保留、六项必填内容和写后读回。正式观点库不参与写入测试。

用户未确认不创建或写入，读取失败不能报告为空库。只有正文匹配或静态校验不足以证明上述行为通过。
