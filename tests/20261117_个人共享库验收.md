# v0.1.5 个人共享观点库验收

日期：2026-11-17。范围为个人路径配置、跨工作区读取和异常处理；不重做 v0.1.4 推敲对话测试。

## 实际行为观察

同一独立 B 审查线程读取本版 Skill，在三个隔离 profile 下处理四次查看请求。测试将指定目录当作用户主目录，不接触真实用户配置或真实观点库。

| 场景 | 实际结果 |
|---|---|
| 首次查看，主目录无配置、当前工作区无旧库 | 告知位置，建立并读回个人路径配置；实际观点库未创建 |
| 从工作区 B 子目录查看，配置指向工作区 A 的既有测试库 | 实际读配置和 A 库，展示原条目，没有在 B 子目录建库 |
| 同一用户改在工作区 B 根目录查看 | 再次读取相同配置和同一 A 库，原条目与文件哈希保持 |
| 配置 JSON 损坏 | 报告解析错误，不覆盖配置，不退回工作区创建空库 |

## 验证边界

这是同一模型线程内的受控行为观察，使用明确给定的测试主目录，不能证明宿主自动发现主目录、自动触发 Skill 或跨模型一致性。线程中断后复用恢复，没有新建独立盲测线程；模型精确型号未独立核验。

主流程另外核对了测试配置、文件是否存在及旧文件哈希，并运行官方 Skill 结构校验。结构和链接检查只证明对应静态条件，不证明实际模型始终遵循规则。

本轮没有测试并发写入、跨设备同步、不可访问的远程共享盘、冲突库自动合并或多模型行为。规则不提供自动合并和设备同步能力。临时覆盖、多个旧库冲突、不支持的配置版本及非绝对路径有规则约束，但未分别进行独立模型实测。真实库写入与保存确认逻辑沿用既有规则，本轮真实观点库内容保持不变。

历史行为观察见 [v0.1.4 验收](20261116_呈现与观点库验收.md)；其旧的每工作区默认存储已被本版个人共享配置替代，不作为现行路径规则。
